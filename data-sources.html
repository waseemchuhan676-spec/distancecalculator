Data Sources & Attribution

World Distance Calculator relies on open-source geographic data, transparent community mapping databases, and established mathematical formulas.

1. OpenStreetMap (OSM)

Mapping data, highway topologies, municipal boundaries, and street networks are provided by the global OpenStreetMap community. OpenStreetMap is open data, licensed under the Open Data Commons Open Database License (ODbL) by the OpenStreetMap Foundation (OSMF).

Learn more about OpenStreetMap Copyright →

2. Nominatim Geocoding

Place name search and geographic coordinate resolution (latitude/longitude) are powered by the Nominatim search engine, operating under OpenStreetMap usage guidelines.

Learn more about Nominatim →

3. Project OSRM (Open Source Routing Machine)

Vehicular road network distance calculations, turn-by-turn coordinate paths, and mathematical route durations are powered by Project OSRM, a high-performance routing engine written in C++ designed to execute shortest-path queries over highway graphs.

Learn more about Project OSRM →

4. Leaflet.js Mapping Engine

Interactive client-side map rendering, zoom controls, and geodesic layer drawing are powered by Leaflet, an open-source JavaScript library developed by Volodymyr Agafonkin.

Learn more about Leaflet.js →

5. Geodesic & Mathematical Standards

Straight-line distance calculations employ the Haversine equation using the WGS 84 mean volumetric Earth radius benchmark of 6,371.0 kilometers (3,958.8 statute miles). Statute mile to kilometer conversions adhere to the international treaty constant (1 mile = 1.609344 km).
